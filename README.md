## 🚀 Featured Projects & Practical Work

### 1. Smart Door Access Log — IoT

**Technologies:** ESP32 · RC522 RFID · Keypad · Servo Motor · LCD · Firebase

A smart lab-entry system designed to support RFID and password-based access. The system combines access control hardware with event logging and a dashboard concept.

- RFID card and keypad password authentication
- Servo-based door lock control with buzzer feedback
- PIR motion sensor and LCD status display
- Firebase Realtime Database for door status and access logs
- Admin/user dashboard concepts for reviewing attempts and managing authorized credentials

**Status:** In progress

### 2. BGPView — Global Network Policy Simulation

**Technologies:** Cisco Packet Tracer · BGP · Routing Policies

A team networking project focused on simulating communication between multiple autonomous systems and exploring routing-policy behavior.

- Multi-AS network topology with eBGP peering
- Route maps and prefix filtering
- Connectivity testing and BGP route inspection
- Link-failure testing and convergence observation

**Type:** Academic team project

### 3. Task Manager Dashboard

**Technologies:** HTML · CSS · JavaScript

A browser-based task management interface built with vanilla JavaScript.

- Add, edit, and delete tasks
- Set task priorities
- Switch between light and dark themes
- Separate HTML, CSS, and JavaScript files

### 4. Web Security & Digital Forensics Labs

**Areas:** Web Application Security · Linux · Network Analysis · Mobile Forensics

Coursework and lab practice focused on identifying, understanding, and documenting security issues in controlled environments.

- Web security topics including SQL Injection, IDOR, XSS, and exposed access logs
- Network discovery and troubleshooting with Nmap and Wireshark
- Digital forensics and Android application analysis topics involving Autopsy, Sleuth Kit, MobSF, JADX, and APKTool
- Emphasis on documenting findings and understanding impact and remediation

**Note:** Security testing is performed in coursework, local labs, or other authorized environments.

### 5. Linux & Docker Practice Labs

**Technologies:** Ubuntu Server · Docker · Docker Compose · Nginx · PHP-FPM · MySQL

Practice deploying and troubleshooting containerized services, working with Linux networking, and managing multi-container environments.
