## 🚀 Featured Projects

### 1. Transformer Specification & BOM Validation System (Graduation Project)
* **Domain:** Electrical Engineering & Automated Verification.
* **Overview:** An intelligent validation system designed to cross-reference customer technical specifications against transformer design documents and Bill of Materials (BOM) data, flagging discrepancies and generating structured review reports for engineers.

### 2. Smart Door Access Log — IoT Security System
* **Technologies:** ESP32, RC522 RFID, Keypad, Servo Motor, Firebase, HTML/JS Dashboard.
* **Overview:** An integrated IoT access control solution featuring multi-factor authentication (RFID + PIN), automated locking mechanisms, real-time event logging, and a web-based monitoring dashboard.

### 3. BGPView — Global Network Policy Simulation
* **Technologies:** Cisco Packet Tracer, BGP, IPv4, Multi-AS Topologies.
* **Overview:** A routing simulation mapping out multi-Autonomous System peering relationships, prefix advertisement, route filtering policies, and convergence analysis under link failures.

### 4. Web Application Penetration Testing Labs
* **Technologies:** Kali Linux, OWASP Juice Shop, Burp Suite, Nmap.
* **Overview:** Comprehensive hands-on assessment documenting common web vulnerabilities including SQL Injection, XSS (Reflected/Stored/DOM), IDOR, missing security headers, and structured remediation reports.

### 5. Arabic PDF-to-Word OCR Converter
* **Technologies:** Python, PyMuPDF, Tesseract OCR, python-docx.
* **Overview:** A local document-processing automation tool designed to extract text, handle scanned pages, and process Arabic-language character and numeral recognition into editable Word documents.
